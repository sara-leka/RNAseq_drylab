# RNAseq_drylab
Complete pipeline for analysis of RNA-seq data starting from the raw sequencing files with preprocessing, quality control, mapping and quantification, and then continuing with downstream data analysis for comparison of mus musculus fibroblast cells (GP38+) in different organs at the steady state. The data is taken from the ["Structural cells are key regulators of organ-specific immune responses"](https://doi.org/10.1038/s41586-020-2424-4) (2020) paper by Krausgruber et al. and is accessible on the NCBI Gene Expression Omnibus (GEO) repository under accession number [GSE134663](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE134663).
